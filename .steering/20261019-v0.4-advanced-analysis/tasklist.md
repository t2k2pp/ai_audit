## 振り返り（2026-10-19）

### 結果
- 全タスク完了。pytest 65 件成功、TypeScript コンパイル成功、Linux 用バックエンドバイナリのビルドと動作（JS/TS/Dart 解析を含む）を確認。
- 実際の LLM（Qwen3.8-Flash-Next 等）での品質確認は未実施（この環境から推論サーバに接続できないため）。

### 計画との差分
- 目次は LLM 生成ではなく「テンプレート＋主要フロー」に変更（小さいモデルでも安定させるため）。
- 設計思想の ChromaDB 依存を廃止し、SQLite＋埋め込み（任意）＋語彙検索にした（拡張の同梱バイナリだけで動かすため）。
- 作業領域の steps/ を全パイプラインで共有し、構造解析が設計書生成の要約を再利用できるようにした。

### 学び
- ダミーサーバの usage でトークン補正係数が学習されるため、テストの予算確認はサーバ側の数え方で行う必要がある。
- 大きなファイルではシンボル一覧（必須部品）が予算を圧迫する。必須部品にも縮約版を用意する。

### 残課題（実機で確認が必要なもの）
- 実モデルでのプロンプト調整（特に compact ティアでの JSON 出力の安定性）。
- 各サーバのコンテキスト長取得 API・tokenize API の実機確認（llama.cpp / vLLM / Ollama）。
- Windows / macOS でのバイナリビルド確認、VSCode 上での動作確認。
- Mermaid 図（クラス図のラベル構文）の表示確認。
